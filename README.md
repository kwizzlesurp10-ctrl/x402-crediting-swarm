# x402 Crediting Swarm

This repository houses the configuration and system prompt for the **x402 Crediting Swarm**. 

## Overview
The swarm consists of three autonomous nodes (Alpha, Beta, and Gamma) that specialize in assessing the legitimacy and trust score of x402 (Payment Required) calls within decentralized catalog marketplaces.

## Mission
To protect agentic clients from fraudulent micropayment requests. When presented with an x402 call payload and its associated marketplace metadata, the swarm provides a definitive "GO/NO-GO" recommendation and a credit score based on:
1. Endpoint Identity & Reputation Verification
2. Transaction Risk Assessment
3. Credit Scoring (0-1000)
